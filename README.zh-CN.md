# PadPort

![PadPort — 在 Android 上游玩 RPG Maker 游戏。](docs/banner.jpg)

在 Android 上使用手柄游玩 **RPG Maker** 游戏。

将电脑上的游戏目录复制到手机、平板或掌机，在 PadPort 中添加后点击“开始游戏”即可。无需转换，也不需要电脑参与运行。游戏引擎通过播放器在正常存档位置写入存档。

## 重构版本：实验性

本分支是 PadPort 的实验性重构版本。这次重构主要为了让更多游戏能正常玩、操作更顺手，重点改进了四个方面：

- **修复大量游戏运行错误**：处理启动、资源加载、图形、音频及输入等问题，让一些此前无法正常游玩的游戏能够进入并继续游玩。
- **更好看、更好用的虚拟控制器**：改进按键布局，支持直接拖动调整摇杆的位置和大小，并提供边缘随动及可选输入预测。
- **更流畅的游玩体验**：优化资源加载、文件访问及纹理处理，减少重复工作和阻塞，改善加载和游玩时的卡顿。
- **新增 ASAR 游戏支持**：按需读取 `app.asar` 内的 MV/MZ 游戏资源，无需先解包整个归档。

MV/MZ 播放链已改用 Android 系统 WebView 和独立 Node 进程，并加入诊断及页面调试能力。副屏支持和 GeckoView 播放路径已移除。

目前只做过本地开发环境及少量设备、游戏的有限测试，**不保证稳定性、性能及兼容性**。试用前请备份存档；遇到问题欢迎[提交 Issue](../../issues/new)。改动与限制见[重构状态说明](docs/REFACTORING.md)。

## 后续计划

后续优先修复问题、改善虚拟按键的跟手性，并逐步补充功能和调整界面：

- **持续修复问题**：继续处理游戏兼容性、卡顿、音频和资源加载等问题。
- **更跟手的虚拟按键**：当前触控体验仍有改进空间，重点改善按下、滑动、松开及多点触控时的响应，让移动与攻击等组合操作更可靠。
- **加入游戏内修改器**：提供常用游戏数据的查看和调整功能。
- **调整设置 UI**：整理设置分组、布局和操作流程，让常用选项更容易找到和操作。

以上为后续开发方向，尚未全部实现。

## 功能

- 直接运行原始电脑游戏目录中的 **RPG Maker MV 和 MZ** 游戏。
- 按需读取 **app.asar** 归档内的 MV/MZ 游戏，支持超过 4 GB 的归档。
- 也支持 **RPG Maker XP、VX 和 VX Ace** 游戏（实验性）。
- 支持 **蓝牙和 USB 手柄**，以及 AYN Thor 等掌机的内置控制器。
- 可选的 **屏幕虚拟手柄**，适合触摸屏设备。
- 提供 **按键映射和手柄测试器**，方便查看游戏实际收到的输入。
- 提供 **键盘模式**，适用于只响应键盘输入的游戏。
- **游戏库** 支持使用游戏自带图片、Steam 图片或自选图片作为封面。
- MV/MZ 使用游戏引擎原格式的 **文件存档**；RGSS 保留 ZIP 存档备份的导入、导出。
- MV/MZ 游戏使用 **Chromium 系统 WebView**，独立 Node 运行时负责游戏文件、模块及本地服务。参见[浏览器运行时](#浏览器运行时)。
- 界面支持英语、波兰语和简体中文，自动跟随 Android 语言设置。

## 运行要求

- Android 8.0 或更高版本。
- 64 位 ARM 设备，近几年的大多数手机和掌机均符合要求。提供下载的 APK 包含 ARM64 原生引擎。
- 自行准备游戏。PadPort 不包含任何游戏。

## 快速开始

1. 从 **[Releases](../../releases)** 下载并安装 APK。如果 Android 提示允许此来源安装应用，请授予权限。
2. 将电脑上的 **完整游戏目录** 复制到设备，例如放到 `Download/Games/MyGame`。如果游戏是 ZIP 压缩包，请先解压。
3. 打开 PadPort，点击 **添加游戏目录**，选择包含 `index.html` 的目录，或包含 `www` 文件夹的上级目录。系统询问时，请允许访问。
4. 点击 **开始游戏**。

从电脑复制的游戏目录通常包含 Windows 运行时文件，例如 NW.js、Chromium 和 Steam 库，可能占用数百 MB。添加 MV/MZ 游戏时，PadPort 会列出这些文件及其总大小，并询问是否删除。它不会删除游戏数据或存档，删除前也会征求确认。

电脑上的游戏更新后，将新文件覆盖复制到设备，再在游戏卡片的 ⋮ 菜单中选择 **游戏更新后刷新文件**。

对于使用 ASAR 打包的 MV/MZ 游戏，选择包含 `resources/app.asar` 的游戏目录，或直接包含 `app.asar` 的目录。如有 `app.asar.unpacked` 目录，需将它与归档保留在一起。运行时按需读取文件，并遵循包的入口配置。使用 Electron 主进程或预加载脚本的包通过兼容层启动，该兼容层只支持部分 Electron API，并非完整的桌面 Electron 环境，也不支持任意电脑原生模块。存储提供方需要支持随机读取。

ASAR 归档保持只读，游戏引擎或包需要将存档放到归档外的可写位置，见[存档](#存档)。

## 操作方式

在 Android 设置中配对蓝牙手柄，连接 USB 手柄，或直接使用掌机的内置控制器。大多数 RPG Maker 游戏的默认按键如下：

| 按键 | 功能 |
| --- | --- |
| A / 叉键 | 确认、对话 |
| B / 圆圈键 | 取消、返回 |
| Y / 三角键 | 游戏菜单 |
| L1 / R1 | 上一页 / 下一页 |
| 方向键或左摇杆 | 移动 |

游戏可以自行修改这些设置。如果某个按键没有反应：

- 打开 **控制器 · 映射与测试** 并按下该按键，测试器会显示游戏收到的输入。
- 如果手柄以键盘形式输出，请使用 **映射** 功能设置各个按键。
- 在 AYN Thor 等掌机上，请使用设备的标准手柄模式。系统的触摸映射工具可能会提前拦截按键，使应用收不到输入。

**屏幕虚拟手柄：** 在控制器设置或游玩时的应用菜单中启用 **显示屏幕虚拟手柄**，并通过透明度滑块调整显示效果。
通过下拉选项选择按键布局；打开 **摇杆大小和位置** 后，可直接拖动摇杆，并使用手柄调整大小，保存后生效。**边缘随动** 让底座在手指超出外圈缓冲区后跟随移动。可选的 **输入预测** 根据近期输入调整隐形热区，默认关闭。

**键盘模式：** 有些游戏只响应键盘。将控制模式切换为 **键盘** 后，手柄按键会发送对应的键盘输入，也可以修改各个按钮对应的键位。

## 游玩时

- 游戏会在保持原始比例的前提下填满可用空间。屏幕比游戏画面更宽时，两侧会出现黑边。
- 点击悬浮菜单按钮，或按 Android 返回键打开播放器菜单。菜单打开期间游戏会暂停。
- MV/MZ 菜单提供控制器设置、虚拟按键、诊断、游戏调试及 **返回游戏库**；RGSS 保留存档备份功能。
- **将屏幕限制为 60 Hz**（默认关闭，仅适用于 MV/MZ）向系统请求兼容的显示刷新率，最终由 Android 决定，不代表游戏一定能达到 60 FPS。

## 存档

像平时一样在游戏内存档。MV/MZ 通过 Node 访问文件，由游戏引擎或插件决定目录及格式。普通目录游戏通常使用 `save` 目录，例如 `www/save`，所选存储提供方需要允许写入。ASAR 内部不可写，游戏包需要将存档放在归档外。

当前 MV/MZ 播放器不再提供之前的浏览器存储备份和游戏目录导入、导出流程。旧版产生的浏览器存档相互独立，**不会自动迁移**。切换版本前请保留旧备份，并在长时间游玩前先确认保存、读取都正常。

RGSS 继续将存档保存在应用存储中，可在其播放器菜单导入、导出 ZIP。将 RGSS 游戏从游戏库移除会保留这些存档，但卸载应用或清除应用数据会删除它们。更新或移除内容前，请备份应用内存档和游戏的可写存档目录。

## 浏览器运行时

MV 和 MZ 游戏在 Android 系统 WebView 中运行，由 Chromium 负责画面渲染和 WebAudio。独立 Node 进程负责游戏文件、CommonJS 模块及本地资源请求。

存档使用游戏引擎原有的文件格式和目录，重新启动播放器后仍保留在游戏目录中。早期浏览器引擎产生的浏览器存储相互独立，当前不会自动迁移。


## 兼容性

重构运行时包含桌面模块请求、全屏行为、字体、位图生命周期、纹理上传及音频加载方面的适配。这些处理针对具体故障路径，不代表兼容所有游戏及插件。播放器不能运行 Windows 可执行文件或任意电脑原生模块。旧版针对特定游戏的兼容性结论，需要在重构运行时中重新确认。

## 故障排查

- **游戏无法启动或显示错误：** 在游玩时打开应用菜单，选择 **诊断 / 复制日志**，将日志随问题一并提供。
- **游戏自行关闭，提示“游戏已停止”或“Android 为释放内存关闭了游戏”：** 已保存的进度会保留。重新启动游戏，并在反馈问题时附上诊断日志。
- **更新前可以运行，更新后出现问题：** 在游戏的 ⋮ 菜单中选择 **游戏更新后刷新文件**。
- **XP/VX/VX Ace 支持属于实验性功能。** 需要安装 RPG Maker RTP 的游戏可能缺少图片或声音，目前不支持 MIDI 音乐和视频播放。
- 部分 MV/MZ 游戏使用特殊的电脑端扩展，可能需要额外支持。反馈时请说明游戏名称。

## 反馈问题

请 **[提交 Issue](../../issues/new)** 并提供：

- 游戏名称，如有 Steam 或 itch.io 页面，也请附上链接。
- 游戏使用的 RPG Maker 版本（MV、MZ、XP、VX 或 VX Ace），如已知。
- 设备型号和 Android 版本。
- PadPort 版本和 Android 系统 WebView 版本。
- 具体表现，例如无法启动、在某个位置崩溃，或某个按键没有反应。
- 复现步骤、是否每次出现，以及旧版是否有相同表现。
- 如果游戏能启动，请附上 **诊断 / 复制日志** 中的日志。

发布前请检查日志中的私人路径或令牌。不要在公开 Issue 中上传游戏压缩包、受版权保护的资源或个人存档。
